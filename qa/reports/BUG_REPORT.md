## Original release blockers

The entries below describe the previous baseline. See [Phase 3 remediation](PHASE3_REMEDIATION.md) for current fixes, verification scope and paths to retests.

- **Critical, reproduced tenant boundary violation.** In every test, a second tenant's adjustment for the same SKU overwrote the first tenant's inventory and reset its reservation. An unauthenticated HTTP request also fetched the first tenant's order by ID with HTTP 200. Stock keys use the SKU only and the API accepts a caller-supplied tenant. Single-process inventory and idempotency locks also leave multi-instance atomicity unverified. Reproduce with the commerce lane. The required remediation is shared transactional reservations, authenticated tenant context, and authorization on order, cart and inventory routes. [Raw reproduction](runs/2026-11-15T03-47-27-747Z-9d72b3e0/commerce/01/observations.json)
- **High, System-X end-to-end certification.** The master demonstration uses distribution-driven simulated arrivals and a separate empirical trace. Calibration calls an endpoint absent from the live Blackbox-X server. Complete canonical replay, add a persisted calibration contract with auditable held-out data lineage, and wire artifact retention into the same master execution. Reproduce with the comparison lane. See [comparison](COMPARISON_REPORT.md).
- **High, ten CRT scenarios.** CRT-04/05/07/08/09/10/11/12/14/15 invoke handlers that explicitly report UNVERIFIED. The independent calls recorded 0/10 executed business tests for each. Whole-suite implementation and scenario-specific invariants are still required.
- **High, Blackbox-X M6.** Calibration and its independent validation gate succeeded 7/10. The remaining runs missed their configured improvement or validation gate. Keep the gate intact and reproduce using `--lane=milestone --feature=M6` on an idle dedicated sandbox.
- **High, Blackbox-X M11/M12.** M11 used a campaign-only query where the API requires a measured run ID and expected a distribution without seeded observations. The live API rejected the input. M12's nested suite stopped at M6 in eight attempts and M11 in two. Generate a real measured fixture and pass its actual run ID, then verify the assertions independently.
- **High, Quorum Lab Raft and faults.** The independent node CLI rejects LEADER/RAFT settings. The separate-process harness therefore verifies quorum replication and recovery. Packet duplication and reordering are not implemented by the inspected fault path, and the storage-fault configuration lacks the required application hook. A Raft-capable executable wiring, durable partition proof, and concurrent history oracle remain open.
